THE SYSTEM THIS ESTABLISHES
Surfaces. Three depths only — page #070B2B, card gradient #17134F→#0C1035 at 1px rgba(139,132,200,.22), inner panel rgba(7,11,43,.6). No glassmorphism, no black rectangles.
Colour roles are fixed. Cyan = live/now. Green = done. Amber = needs you. Violet→magenta = the one primary action per screen. Magenta = blocked. Everything else is white or #B9B9D5.
The journey metaphor appears once. The taught → homework → quiz path inside Today's Learning, built from real text and glowing nodes so it carries live data and stays editable. The hero scene carries the aspiration; the path carries the meaning. Nothing else is dotted, which is what keeps it an identity rather than decoration.
Radii & type unchanged. 26px cards, 20px tiles, 16px buttons, 999px chips; same Plus Jakarta scale as the approved screens, so nothing about legibility shifts.
One lighting direction — top-left, cool rim light, warm accent low and to the right. Every feature object obeys it.
TWO THINGS TO DECIDE
1 · The four Quick Control visuals. Real photographic objects — phone with a lock, a child pinned on a map, a phone showing the report, an app grid with blocked apps — regraded into the night palette so they sit in this world. Same treatment already prepared for Reels, Security and Device, so C1 is a layout job. Commissioned 2.5D renders drop into the identical frames later.
2 · The hero scene. Your reference crop, line and all, fading into the page. For production you'll want the line as live text over a commissioned scene — and one scene per time of day (evening shown) so the top of Home changes through the day with no layout change.
DELIBERATELY NOT DONE
Your brief sketched a separate Today at School section. Rather than add a section to an approved IA, that taught → homework → done → scored journey now lives as the path inside Today's Learning, where the parent already looks for it. If you'd rather it be its own full-width section on Home, say so and I'll promote it — every other screen is now drawn.

WHY NO BAR CHARTS
Every subject is a path of nodes: filled green = passed, magenta = failed, amber = needs practice, hollow = not started. One glance gives the shape of the week without reading a single axis.
The quiz trend is the same language turned vertical — height is the score, and today is the brighter cyan node. No gridline labels, no legend.
Only the screen-time split stays a bar, because proportion is the whole point there.
