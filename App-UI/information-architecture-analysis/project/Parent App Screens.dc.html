RULES THIS SET FOLLOWS
One primary action per screen. Crimson is used once — everything else is a quiet secondary.
Every settings screen states its outcome in a sentence before it offers a control ("Every weekday, 3–6 PM, only study apps open").
Consequential actions confirm. Lock, unblock, remove child and PIN changes all pass through a sheet.
Five alert types only — missed study, blocked-app attempt, tamper, device offline, location issue. Each is what happened → why it matters → one fix.
Imagery carries meaning, so a parent recognises a feature before reading its label. Placeholders are cropped from your reference at final sizes.

WHY THIS ORDER
Child before permissions. The parent names a real child first, so every permission afterwards is asked on Aalya's behalf, not the app's.
Study time before Home. Setting the window during setup means Home has content on day one instead of an empty state — the single biggest cause of churn in the old app.
PIN offered, not forced. It's step 4 on the done screen, so setup can finish in one sitting and the parent still gets nudged.
