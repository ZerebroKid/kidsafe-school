Screen map — what goes where

Read this page first. Every Figma page is numbered in build order. Inside each page, screens run left to right in the order the student meets them. Frame names match the class names in the markup, so a screen in Figma maps 1:1 to a component in code.

Figma pages, in build order
01
Design System Build this into your theme file before any screen. Colours, type scale, spacing (4px base), radius, elevation, icons, buttons, cards, progress, navigation. Nothing else may introduce a new value. theme / tokens · shared widgets
02
Onboarding & Home ← use v2, ignore v1 First launch: Splash → Popup 1 (rewards, ₹150 price comparison) → Popup 2 (no tuition needed) → Home. Popup copy is locked marketing copy — do not shorten a single line. Home has no XP, coins, streak or leaderboard. SplashActivity · OnboardingPopup1 · OnboardingPopup2 · HomeFragment
03
Learn Navigation Study tab: Subject list → Subject detail (chapters) → Topic detail. Topic detail is the 7-section journey with the quiz as the final gate; three states shipped (not started / mid / all done). Locked rows must always state why they are locked. SubjectListFragment · SubjectDetailFragment · TopicDetailFragment
04
Learning, AI & Quiz The 7 section screens, AI Doubt chat, quiz flow and results. No lives or hearts — "Try again" is always available, and every wrong answer shows the correct one plus a one-line reason. Quiz result posts to parent and teacher. SectionFragment (×7) · AiDoubtFragment · QuizFlowActivity · QuizResultFragment
05
Rewards, Focus & Profile Rewards (Marina Restaurant is the only live partner — every other category renders in the "Opening soon" state), Focus Mode incl. the parent-locked variant, AI Exam Predictor, Profile with the parent's report card, Settings. RewardsFragment · FocusModeActivity · ExamPredictorFragment · ProfileFragment · SettingsFragment
06
Junior (Nursery – Class 5) — separate app mode Do not mix with Class 6–12. Different font (Baloo 2), different palette, no bottom nav at all: Home tiles open Fun / Cartoons / Reels / Games and the top-left back arrow returns Home. Fun is a full-body Zumi stage with a mic as the only control; page 02b lists all nine Zumi action assets by filename. JuniorHomeFragment · JuniorFunFragment · JuniorCartoonsFragment · JuniorReelsFragment · JuniorGamesFragment
Rules that apply to every screen No XP, coins, levels, streaks, leaderboards or achievements anywhere in Class 6–12. Motivation is one loop: today's mission → topic → quiz → unlock reward. No emoji in product UI — use the icon set from page 01. Any feature that is not live on launch day carries the "Coming soon" ribbon. Light app throughout; the dark surface (#14142B) is only for video, Focus Mode, formula blocks, the quiz and Junior Games. Frame is 390 × 844, side padding 20, bottom nav 72. All spacing is a multiple of 4.
Blocked until you supply assets Every photo and character in these files is an AI-generated stand-in. Cartoon stills, game art, food and product photography, and the Zumi character must be replaced with owned or licensed artwork in the same slots before release. The ZerebroKid logo is still a gradient "Z" placeholder on Splash. The ₹200 / ₹230 / ₹150 comparison needs signed partners per category; only Marina Restaurant is signed today.
